Ladder Graph is an offline-first visual compiler that lets you design agent workflows on a canvas, validate them against a semantic rule engine, and compile a single self-contained artifact for Codex, Claude, Hermes Agent, Python, or TypeScript. Everything runs in your browser — no accounts, no cloud sync, and no connection to model providers.

## What Ladder Graph Does

Ladder Graph is a **compiler**, not an agent runtime. It takes a workflow you describe visually or in YAML and produces one deterministic, portable artifact — a Markdown skill file or a typed data module — that you hand to an agent harness or import into your own code.

## Compilation Targets

Choose the target that matches your agent harness or codebase:

| Target | Output | Use When |
|--------|--------|----------|
| `codex` | Markdown `.md` with Skills frontmatter | OpenAI Codex / `AGENTS.md` workflows |
| `claude` | Markdown `SKILL.md` | Anthropic Claude skill files |
| `hermes` | Markdown with `metadata.hermes` | NousResearch Hermes Agent skills |
| `python` | `.ladder.py` typed data module | Python host applications |
| `typescript` | `.ladder.ts` typed data module | TypeScript/Node.js host applications |

## Getting Started

<Steps>
  <Step title="Open the Studio">
    Navigate to the Ladder Graph PWA. No installation is required — it runs entirely in your browser and works offline after the first load.
  </Step>
  <Step title="Pick a Template">
    Choose one of the 16 outcome-led starter workflows from the welcome screen. Templates cover patterns like draft–critique–revise, parallel risk review, evidence synthesis, and more.
  </Step>
  <Step title="Customize Nodes">
    Select any node to open the inspector. Edit its role, prompt, skills, connectors, and output schema. Changes sync immediately to the YAML editor.
  </Step>
  <Step title="Validate and Compile">
    Open the compiler drawer, select your target, and click **Validate**. Fix any diagnostics, then click **Compile** to download or copy your artifact.
  </Step>
</Steps>

<Note>
  Ladder Graph never executes nodes, calls model providers, or stores credentials. Generated artifacts are text files — import them into your agent harness and bind handlers explicitly.
</Note>
